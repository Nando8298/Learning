Project Overview
This project predicts the survival rate or vannamei shrimp using water quality data and farm cycle information. 
The goal is to provide an early warning tool for farmers so they can adjust water quality and management before heeavy mortality occurs.

Dataset:
Samples : 1131 pond day records from 10 ponds
Problem type: Regression (predicting mortality)
Source : Real collected farm data
